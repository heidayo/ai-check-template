# v0.2.0-alpha.0 Release Notes

Date: 2026-05-16
Package: `ai-check-template@0.2.0-alpha.0`
Dist-tag: `next`

## Summary

`ai-check-template` is now published to npm as an alpha CLI package. Early adopters can try the CLI with the `next` dist-tag while the manual template path remains supported.

```sh
npx -y ai-check-template@next init --target . --profile react-nextjs --dry-run
```

This is an alpha release, not a stable v0.2.0 release.

## Included

- `init` for copying templates, merging package scripts, selecting profiles, choosing CI mode, and optionally installing dev dependencies
- `doctor` for read-only drift diagnostics across scripts, files, CI workflows, Claude hooks, profile warnings, and strict warning mode
- `update` for guarded repair of known managed files, profile docs, package scripts, CI workflows, and Claude hook commands
- Install state tracking through `.ai-check-template.json`
- Package-manager-aware rendering for npm, pnpm, yarn, and bun command surfaces
- Public npm package contents validated by pack and publish dry-run checks

## Limitations

- The package is published under `next`; use explicit `@next` while it remains alpha.
- Stable `v0.2.0` release notes and release tagging are separate follow-up work.
- Manual copy from `package-templates/` remains supported for teams that do not want a CLI bootstrap step.
- Installing or configuring project-specific test tools is still the target project's responsibility.
