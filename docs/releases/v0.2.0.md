# v0.2.0 Release Notes

Release date: 2026-05-16
Package: `ai-check-template@0.2.0`
Dist-tag: `latest`

## Highlights

- Stable CLI scaffolding for `init`, `doctor`, and `update`.
- Profile-aware package scripts for `react-nextjs`, `react-vanilla`, `expo-rn`, `node-cli`, and `supabase-rls`.
- Package-manager-aware command rendering for `pnpm`, `npm`, `yarn`, and `bun`.
- Install state tracking through `.ai-check-template.json`.
- Read-only diagnostics for script drift, file drift, CI workflow drift, Claude hook drift, profile warnings, missing referenced package scripts, and stale managed CI workflows.
- Guarded update flow for known managed files, package scripts, profile docs, CI workflows, and Claude hook commands.
- Optional dev dependency install with `--install-deps`.
- Historical alpha package: [`v0.2.0-alpha.0`](./v0.2.0-alpha.0.md).

## Install

After the stable package is published, use the default npm package path:

```sh
npx -y ai-check-template init --target . --profile react-nextjs --dry-run
npx -y ai-check-template init --target . --profile react-nextjs --yes
npx -y ai-check-template doctor --target .
npx -y ai-check-template update --target . --dry-run
```

Manual copy from `package-templates/` remains supported for teams that want to inspect and adapt files without a CLI bootstrap step.

## Verification

Repository validation:

```sh
node --test tests/cli/*.test.mjs
npm pack --dry-run --json
npm publish --dry-run --tag latest --json
make validate
bash scripts/sage-validate.sh
```

Expected repository state:

- `package.json` version: `0.2.0`
- stable publish preflight: `npm publish --dry-run --tag latest --json`
- no runtime source changes from the alpha CLI implementation

Post-publish smoke:

```sh
npm view ai-check-template version dist-tags --json
npm init -y
npx -y ai-check-template init --target . --profile node-cli --package-manager npm --ci none --dry-run
npx -y ai-check-template init --target . --profile node-cli --package-manager npm --ci none --yes
npx -y ai-check-template doctor --target . --profile node-cli --package-manager npm --ci none --json
```

Expected publish state:

- version: `0.2.0`
- `latest`: `0.2.0`
- `next`: remains available for the alpha history unless the maintainer intentionally changes it later

## Publish

The release prep PR does not write to npm. After the PR is merged and `main` is clean, the maintainer can publish with:

```sh
git switch main
git pull --ff-only
make validate
npm publish --tag latest --access public
```

Then create the Git tag and GitHub Release only after the npm publish and `npx` smoke test pass.

## Limitations

- This release prepares the stable `0.2.0` package; actual npm publish requires maintainer authentication.
- The CLI installs generated templates and managed support files, but it does not install external tools such as Supabase CLI, Maestro, or React Doctor.
- Existing files and scripts are preserved unless an explicit overwrite or update path owns the managed content.
- GitHub Actions Composite Action and Marketplace listing remain v0.3.0+ work.
