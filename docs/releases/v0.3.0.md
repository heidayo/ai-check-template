# v0.3.0 Release Notes

Release date: 2026-05-16
Release type: GitHub Actions integration
Git tag: `v0.3.0`
Package: npm package remains `ai-check-template@0.2.0`

v0.3.0 is a GitHub Actions integration release. It is not an npm package release and does not change the CLI package version.

## Highlights

- Hosted reusable workflow at `.github/workflows/ai-quality.yml`.
- Composite Action at `ai-quality/action.yml`.
- External repositories can pin the hosted workflow or action with `@v0.3.0`.
- Shared inputs for `package-manager`, `node-version`, `install-command`,
  `check-command`, `working-directory`, and `upload-ai-check-artifacts`.
- `pnpm`, `npm`, `yarn`, and `bun` install paths with explicit package manager
  validation.
- Least-privilege hosted workflow permissions: `contents: read`.
- GitHub Actions guide in [`../github-actions.md`](../github-actions.md).
- Structural validation guards for the hosted workflow, action, guide, and
  release docs.

## Install

Use the hosted reusable workflow when you want this repository to own the
workflow body:

```yaml
jobs:
  ai-quality:
    uses: heidayo/ai-check-template/.github/workflows/ai-quality.yml@v0.3.0
    with:
      package-manager: pnpm
      node-version: "22"
      check-command: pnpm ai:check
```

Use the Composite Action when you want to keep the workflow in your repository
but reuse the setup/install/check steps:

```yaml
jobs:
  ai-quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
      - uses: heidayo/ai-check-template/ai-quality@v0.3.0
        with:
          package-manager: pnpm
          check-command: pnpm ai:check
```

The npm CLI remains available as `ai-check-template@0.2.0`:

```sh
npx -y ai-check-template init --target . --profile react-nextjs --dry-run
```

## Limitations

- v0.3.0 does not publish a new npm package version.
- GitHub Marketplace listing is planned, not completed in this release.
- The future `@v1` major alias is planned after the workflow and action
  contracts have more external usage.
- The Composite Action assumes the target repository has already been checked
  out.
- Target projects still need their own `ai:check` script or a custom
  `check-command`.
