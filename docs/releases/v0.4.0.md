# v0.4.0 Release Notes

Release date: 2026-05-19
Release state: release-ready, npm publish pending
Package: `ai-check-template@0.4.0`
Dist-tag target: `latest`

v0.4.0 is the next npm CLI release candidate. It packages the repository-current CLI upgrades from SPEC-0049 through SPEC-0053. npm publish, the `v0.4.0` git tag, and GitHub Release creation remain explicit maintainer follow-up work.

## Highlights

- `ai-check-template run` executes a target package script and emits structured `PASS` / `FAIL` / `SKIPPED` evidence with timing, exit code, and redacted stdout/stderr.
- `ai-check-template expect` validates structured AC / Test Matrix files in JSON or the packaged YAML subset.
- Packaged AC / Test Matrix schema and examples: `ac-test-matrix.schema.json`, `ac-test-matrix.example.json`, and `ac-test-matrix.example.yaml`.
- `ai:check:secure` now chains `security:secrets`, `security:deps`, `security:supply-chain`, and `security:sast`.
- Claude Code hook matcher now covers `Edit`, `Write`, `MultiEdit`, and `NotebookEdit`.
- The first-look usage map connects `plan-first`, QA prompts, structured test design, local checks, diagnostic repair, security scan, CI, and review prompts.

## Install

After publish:

```sh
npx -y ai-check-template@latest --help

npx -y ai-check-template@latest run --target . --script ai:check --json
npx -y ai-check-template@latest expect --file docs/ai-check-template/docs/ac-test-matrix.example.json --json
```

## Limitations

- This release prep does not publish to npm by itself.
- `ai-check-template run` intentionally splits explicit `&&` script chains; complex shell orchestration should stay in target project scripts.
- `ai-check-template expect` supports JSON and the packaged YAML subset, not arbitrary YAML.
- `ai:check:secure` provides entry points, but target projects still own scanner installation, auth, allowlists, and organization-specific rules.
- The Claude hook matcher depends on Claude Code tool names continuing to recognize `Edit`, `Write`, `MultiEdit`, and `NotebookEdit`.
