# v0.1.0 - Manual Templates for AI Code Verification

Release date: 2026-05-14

`ai-check-template` v0.1.0 is the first public manual template release. It is for teams that want to copy verification templates into an existing project and make AI-generated code pass explicit checks before merge.

This is not an npm package release. CLI scaffolding such as `npx ai-check-template init` is planned for v0.2.0 or later.

## Highlights

- English-primary README with Japanese version.
- Philosophy docs for Formal Name Match, Test Pyramid, Given-When-Then, and QA techniques.
- Prompt templates for plan-first work, test design expansion, permission checks, and diagnostic repair.
- `ai:check` / `ai:check:fast` shell entry points and npm scripts fragment.
- GitHub Actions examples, including direct workflows and reusable workflow prototypes.
- Five profile guides: `react-nextjs`, `react-vanilla`, `expo-rn`, `node-cli`, and `supabase-rls`.
- Runnable `examples/nextjs-basic` Before / After example.
- Initial public dogfooding report with limitations clearly stated.

## Install

v0.1.0 is copy-and-adapt.

```bash
git clone https://github.com/heidayo/ai-check-template.git
cd ai-check-template
```

Then copy only the template pieces your project needs. A typical Next.js project starts with:

```bash
cp -r package-templates/scripts ./scripts
cp package-templates/package.scripts.fragment.json ./package.scripts.fragment.json
cp package-templates/ci-examples/github-actions/ai-check.yml .github/workflows/
cp package-templates/ci-examples/github-actions/ai-check-fast.yml .github/workflows/
```

Merge the scripts fragment into your own `package.json`, then adapt commands to your project.

## Limitations

- v0.1.0 does not publish an npm package.
- v0.1.0 does not provide `npx ai-check-template init`.
- v0.1.0 is not Phase 2 CLI graduation evidence.
- The initial dogfooding report is repository-internal plus example-based, not external production project data.
- Template commands may need adaptation to each project's package manager, test runner, and CI environment.
